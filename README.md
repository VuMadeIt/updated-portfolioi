# Lucas Vu portfolio

Personal portfolio site for [Lucas Vu](https://lucasvu.com).

**Live site:** [https://lucasvu.com](https://lucasvu.com)

## Stack

- Next.js + React + TypeScript
- Sanity CMS (`studio-lucas-vu/`)
- Tailwind CSS
- Hosted on Vercel

## Local development

```bash
npm install
npm run dev
```
